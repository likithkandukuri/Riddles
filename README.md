# Escape Room 3000
A colorful text-based riddle adventure written in Python using `colorama`!

## How to Play
Solve riddles to escape through 3 doors. Each room has two riddles — answer both correctly to move forward.
If you fail, you can choose to reset or quit.

## Requirements
- Python 3.8+
- colorama

## Installation
```bash
pip install colorama
